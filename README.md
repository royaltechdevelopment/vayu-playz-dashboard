# Vayu Playz Dashboard

Build a responsive React + TypeScript frontend for **Vayu Playz Official**, closely matching my two uploaded design reference images.



**Pages:**



1. Login page with cinematic Minecraft-inspired background, dark navy theme, purple-blue neon glow, glassmorphism and a Discord login demo button.

2. Server List page with the same theme, a left sidebar containing only Dashboard, Support and Documentation, plus a top-right clickable profile avatar dropdown.



**Server List:** Create a reusable, beautifully styled ServerCard component with server icon, name, member count, bot status and action button. Do not display mock servers, fake profile data or fake counts. Show a polished empty state until real Discord data is connected. Prepare the card component to accept real data through props later.



**Interactions:** Demo navigation between both pages, working search/filter UI when real data is available, profile dropdown, and toast messages.



**Restrictions:** Frontend UI only. No backend, database, OAuth, API calls or Discord integration. Use reusable components, responsive layouts and the exact visual style of both references. Keep code simple to minimize Lovable credits. Login must be the initial page, with a demo link to preview the Server List.
